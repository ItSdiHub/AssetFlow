# SDI IT Asset Hub 🚀
> **نظام إدارة العهد والأصول التقنية ومكتب المساعدة الفنية المتكامل**  
> *Enterprise IT Asset Management & Helpdesk Service Hub*

---

## 📋 Overview / نبذة عن النظام

**SDI IT Asset Hub** هو نظام ويب شامل وحديث لإدارة دورة حياة الأصول والعهد التقنية، يربط بشكل متكامل ومبسط بين:
**الموظف ➔ الأصل/العهدة ➔ مكتب المساعدة (Helpdesk) ➔ الصيانة الدورية والطارئة ➔ السجل التاريخي والتدقيق**

يتميز النظام بتجربة مستخدم تفاعلية راقية، تدعم وضع العمل **المحلي دون اتصال (Offline-First)** والمزامنة السحابية المباشرة مع **Supabase (PostgreSQL)**، مع فصل لغوي صارم وثنائي الاتجاه بين **العربية والإنجليزية**.

---

## ✨ Key Features / المميزات الرئيسية

### 1. 🖥️ إدارة الأصول والعهد التقنية (IT Asset Management)
- شجرة تصنيفات هيكلية ذكية (أجهزة مكتبية، حواسيب محمولة، شاشات، خوادم، طابعات، شبكات، برمجيات ورخص).
- تتبع تفصيلي لمواصفات العتاد (المعالج، الذاكرة، التخزين، عنوان MAC، عنوان IP، نظام التشغيل، الرقم التسلسلي، وموقع التثبيت).
- تتبع حالات الأصول في الوقت الحقيقي (متوفر، معهد لموظف، قيد الصيانة، خارج الخدمة، مستهلك).

### 2. 🤝 تسليم واستلام وتوثيق العهد (Custody & Handover Workflow)
- دورة استلام وتسليم موثقة (`Asset Handover`) مع تسجيل:
  - الموظف المستلم (`Assigned To`).
  - تاريخ الاستلام (`Assignment Date`).
  - المسؤول عن التعيين (`Assigned By`).
  - الموقع والقسم (`Location & Department`).
  - ملاحظات حالة الجهاز عند التسليم (`Condition Notes`).
- إمكانية تأكيد الاستلام من قبل الموظف عبر حسابه أو رقم التذكرة.
- إمكانية نقل العهدة من موظف لآخر (`Transfer Asset`) أو إرجاعها إلى المستودع (`Return Asset`).

### 3. 🎫 مكتب المساعدة والتذاكر الفنية (Integrated Helpdesk)
- فتح تذاكر دعم فني مرتبطة مباشرة بالجهاز والعهدة المخصصة للموظف.
- نافذة محادثة تفاعلية مباشرة (`Chat & Messages`) بين الفني والموظف داخل التذكرة مع سجل بالوقت والتاريخ.
- تحديث فوري لحالة التذكرة (مفتوحة، قيد المعالجة، بانتظار العميل، تم الحل، مغلقة).

### 4. 🛠️ سجل الصيانة والإصلاح (Maintenance & Repair Tracking)
- تحويل تلقائي للأجهزة المتعطلة إلى قسم الصيانة من شاشة الأصل أو من خلال تذكرة الدعم الفني.
- تتبع تكلفة الإصلاحات، قطع الغيار المستبدلة، واسم الفني المسؤول.
- توثيق الإجراءات التصحيحية وسبب الإغلاق وملاحظات الفحص النهائي.

### 5. 🏷️ طباعة الباركود والملصقات الذكية (QR Code & Labels)
- توليد تلقائي لرموز الاستجابة السريعة (QR Codes) والباركود لكل أصل.
- نافذة مخصصة لطباعة بطاقات الأصول (`Asset Labels`) بأبعاد قياسية مناسبة للطباعة الحرارية أو الورقية.

### 6. 🌐 فصل لغوي كامل وصارم (100% Strict Bilingual AR/EN)
- **في الواجهة العربية**: واجهة عربية أصيلة وواضحة، مع الحفاظ على المصطلحات التقنية العالمية المتعارف عليها (مثل IT, QR, PDF, USB, MAC, إلخ).
- **في الواجهة الإنجليزية**: **صفر أحرف أو كلمات عربية** في كامل أرجاء النظام (الشريط الجانبي، الترويسة، الجداول، النوافذ المنبثقة، الإشعارات السريعة Toasts، ملصقات الطباعة، وقواعد البيانات الافتراضية).

### 7. ☁️ دعم السحابة والعمل دون إنترنت (Offline-First + Supabase Sync)
- عمل فوري وتلقائي عبر المتصفح باستخدام التخزين المحلي والذاكرة المؤقتة دون الحاجة لتهيئة معقدة.
- تكامل سلس وسريع مع قاعدة بيانات **Supabase (PostgreSQL)** للمزامنة المركزية والنسخ الاحتياطي اللحظي.

### 8. 🛡️ إدارة الصلاحيات والمستخدمين (RBAC)
- **مدير النظام (Admin)**: تحكم وإشراف كامل في جميع الإعدادات والأصول والمستخدمين وسجلات التدقيق.
- **فني الدعم (Technician)**: معالجة التذاكر، تسجيل الصيانة، وفحص ونقل العهد.
- **الموظف (Employee)**: عرض الأجهزة والعهد المستلمة، تأكيد الاستلام، وفتح ومتابعة تذاكر الدعم.
- **المشاهد (Viewer)**: الاطلاع والتقارير دون إمكانية التعديل.

## 🚀 Getting Started / تشغيل المشروع

### الطريقة الأولى: التشغيل السريع المباشر (Direct Run)
يمكنك فتح ملف `index.html` مباشرة في أي متصفح حديث (Chrome, Edge, Firefox, Safari) وسيعمل النظام بكامل وظائفه وقواعد بياناته المحلية فوراً.

### الطريقة الثانية: عبر خادم محلي (Local Server)
1. **باستخدام ملف التشغيل (Windows)**:
   - قم بالنقر المزدوج على `run.bat`
2. **باستخدام Node.js**:
   ```bash
   node server.js
   ```
3. **باستخدام Python**:
   ```bash
   python -m http.server 8085
   ```
ثم افتح الرابط: `http://localhost:8085` في متصفحك.
